# RQ3: Explanation Control

This experiment branches each of the five final RQ1 RGB6 B-cos PPO B=2.3
models into four matched 150k-transition continuations:

- `pure`: unchanged PPO continuation, explanation coefficient 0;
- `sequential`: agent and current objective as P, walls/grid lines as N;
- `local`: action-conditioned local affordance P/N mask;
- `flipped`: exact sequential mask with P and N exchanged.

All three supervised branches use `masked_absolute_energy`, coefficient 0.15,
and maximum explanation-to-PPO actor-gradient ratio 0.1. Thus the flipped
branch changes only mask semantics, not the objective.

## Training

Create the 20-run grid locally:

```powershell
python minigrid_part/sweep_rq3_ppo_continuations.py --create-sweep
```

Replace `SWEEP_ID` in
`experiments/rq3_legacy_energy_ablation/condor/rq3_ppo_continuations.sub`, commit
and pull on the cluster, then submit:

```bash
condor_submit experiments/rq3_legacy_energy_ablation/condor/rq3_ppo_continuations.sub
```

Every run saves 50k/100k/150k checkpoints, a final model, source/final hashes,
configuration, final 100-episode stochastic policy evaluation, runtime, FPS,
and W&B training diagnostics. Model ZIPs are W&B artifacts and are ignored by
Git locally.

## Evaluation

After downloading the 20 final models into the generated continuation layout:

```powershell
python minigrid_part/run_rq3_evaluation.py
```

For each seed this performs:

- 100 stochastic policy episodes with identical evaluation seeds;
- one shared 256-state/action RGB6 dataset generated by the pure continuation;
- sequential, local, and flipped-mask alignment for every model;
- deletion/insertion with random controls;
- comprehensiveness, sufficiency, Sensitivity-n, and infidelity;
- valid empty-grid primary substrate and all-six-zero sensitivity substrate;
- representative movement, valid-interaction, and invalid-interaction figures.

The final aggregation uses the five independent source/training seeds as the
statistical unit and writes JSON and CSV summaries under `final/`.
